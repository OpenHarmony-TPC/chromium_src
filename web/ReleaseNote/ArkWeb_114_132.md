# ArkWeb 版本的差异总结

Chromium 上游社区 114 到 132 版本大颗粒变更共 **377 **项，带来了更多 W3C 新特性，以及安全，性能，稳定性提升外，识别出需要前端开发者注意及适配的，包括 W3C 规格废弃，安全限制，以及规格实现错误修复等共计 50 项。

# 114内核 -> 132 内核带来的收益总结

1. 安全能力提升：修复漏洞，更严格的跨域访问限制，防止广告等引导用户点击行为。
2. 性能提升：132 内核较 114 内核部分场景在功耗以及滑动体验上均有提升。
3. 新增 W3C 功能及特性：
   
   * Scroll-driven animation  更好性能的滚动驱动动画。
   * Shared storage API 存储共享。
   * Display and content-visibility animations 元素显示隐藏支持 css 动画。
   * Device Posture API – 折叠屏 API。
   * View Transitions Same-Origin Navigation 同源页面跳转动画。

# 开发者适配注意事项

### 上游社区带来的适配注意事项

OpenHarmony 的Web内核跟随系统进行升级，系统版本升级覆盖需要一定周期，导致线上将同时出现两个内核版本，Web 业务需同时兼容两个版本内核，ArkWeb 团队已识别出需要注意的场景如下，方便开发者进行适配。
排查范围包括：Chrome Release Note，Chromium issue list，WPT，XTS 测试结果，头部生态应用摸测等。

需要开发者特别注意的内容包含：

1. 移除了 TLS 1.0 1.1 协议版本的支持。
2. 移除不安全的 Theora 视频编解码器。
3. 跨域跳转时，移除 Authorization header。
4. WebSQL 已被完全废弃。
5. input 组件如果为 disabled 状态，则不再接收 click 事件。
6. cookie 中包含控制字符，则撤销本次写入。
7. 为了安全，跨域 iframe 如自动移动过，则短时间内的事件将被丢弃。
8. 跨域 iframe 间，禁止拖拽(https://issues.chromium.org/issues/326639460)。
9. css grid display 类型，与 aspect-ratio 共用，有不少显示异常问题，上游社区修复中。

### 未跟随特性

部分 Chromium 社区引入的变更，模测 TOP 应用时发现对应用主链路有影响。
