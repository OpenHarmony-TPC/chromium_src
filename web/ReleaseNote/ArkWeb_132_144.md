# ArkWeb版本的差异总结

HarmonyOS 7.0系统ArkWebCore内核默认升级到了M144版本。Chromium上游社区从133到144版本共发布323项特性，带来了更多W3C新特性，以及安全，性能，稳定性的提升。内核升级也会引入不兼容性变更的潜在风险，需要开发者关注并及时适配。

# 132内核 -> 144内核带来的收益总结

Chromium升级到144之后在安全，性能，功能上都有提升。新内核对V8沙箱持续加固，修复绕过漏洞，漏洞利用难度显著增加。优化了GPU安全架构，显著降低图形栈安全攻击面。新增了隐私保护机制，防止跨站点追踪。性能上在JSBridge方面实测有明显提升。在CSS标准演进上新增诸多特性如，CSS Anchor Positioning锚点控制，CSS 'stretch'关键字，CSS符号相关函数abs()、sign()，CSS env()环境变量，CSS progress()进度函数，CSS Gap Decorations间隙装饰等功能，CSS开发体验显著改善。
